# Lasang Pinoy Frontend

This repository contains a PHP + CSS conversion of the Lasang Pinoy landing page mockup.

## Run locally

1. Start a local PHP server from the project root:
   ```bash
   php -S localhost:8000
   ```
2. Open in your browser:
   ```text
   http://localhost:8000/
   ```

## Files

- `index.php` — page structure and content
- `assets/css/style.css` — styling for the design

The page is built to closely match the provided reference and is responsive for smaller screens.

## Notes

The example uses remote Unsplash photography for the hero and recipe visuals. Replace those URLs with local assets if you want a fully self-contained project.
